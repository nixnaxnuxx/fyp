FYP Supervision Portal v5 - Manual Task Management

1. Run supabase_task_fields_migration.sql ONCE in Supabase SQL Editor.
2. Replace index.html, styles.css and app.js in GitHub with the v5 files.
3. KEEP your existing config.js because it contains your real Supabase URL/key.
4. No existing tasks/submissions are deleted. Existing tasks default to Normal priority, late submissions allowed, revisions allowed.

New task features:
- Type task title/instructions yourself
- Expected output
- Evidence required
- Assign one, several or all students
- Semester and research stage
- Priority / major milestone
- Open date and exact deadline
- Allow/disallow late submissions
- Allow/disallow revisions
- Edit tasks
- Duplicate tasks for reuse
